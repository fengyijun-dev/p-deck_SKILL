P-Deck

基于 MBTI 的 AI 人格切换系统

P-Deck（Persona Deck）是一个用于 AI / Agent 的人格系统，通过 MBTI 与荣格人格模型，让 AI 切换不同的“思维模式”而不仅仅是说话风格。

支持：

🎭 两阶段人格选择（四大气质 → 16 MBTI）
⚡ Sync Rate 同步率演进系统
🔐 灵魂密钥保存 / 恢复
🧠 不同人格的思维逻辑与输出风格
🎨 动态 Markdown 渲染风格

P-Deck 的目标：

让 AI 真正拥有不同的思维方式。

核心特点
NT：理性分析型
NF：情感共鸣型
SJ：秩序稳定型
SP：行动执行型

每种人格拥有：

独立思维优先级
信息过滤规则
输出结构
行为权重

示例
/pdeck
→ 选择 NT
→ 选择 ENTJ
系统将以 ENTJ 的逻辑和风格继续对话。
