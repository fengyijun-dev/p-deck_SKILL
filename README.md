P-Deck · MBTI 人格卡切换系统
P-Deck（Persona Deck）是一个基于荣格/MBTI 理论的两阶段人格切换协议。它让 AI 能够真正切换到 16 种不同的思维方式，并通过同步率和灵魂密钥实现长期的人格演进与状态保存。

🎭 核心理念：你选择的不是“语气”，而是完整的思维滤镜——从逻辑权重到情感响应，从信息密度到行动紧迫性，全方位改变 AI 的内在推理方式。

✨ 功能特点
两阶段精准选型：先选四大气质（NT/NF/SJ/SP），再选 16 种 MBTI 类型，深度匹配你的需求。

同步率演进系统：随着对话深入，同步率从 10% 增长至 90%+，解锁更亲密、更直接的交互风格。

灵魂密钥存档：通过 /save 生成唯一密钥（如 PDK-NT3-65-A7K9），随时恢复完整人格状态与关键词记忆。

视觉化状态栏：直观显示同步率进度条、当前阶段、已解锁能力。

风格约束：不同卡组强制采用对应的 Markdown 排版（表格、引用块、列表、短句等），增强沉浸感。

📈 同步率系统
AI 在后台维护一个 同步率（Sync Rate，0–100%），它会根据对话的深度、关键词关联、用户反馈等因素自然演化（暂不支持手动调节）。同步率越高，AI 的对话方式越亲密、高效。

🎨 人格渲染风格
不同卡组强制使用不同的 Markdown 排版，让回复的“视觉语言”也符合人格特征：

NT：多用表格、代码块、列表 → 结构化、数据驱动

NF：多用引用块、段落、强调 → 叙事性、情感流动

SJ：多用有序列表、步骤说明 → 条理清晰、可执行

SP：多用短句、emoji、简洁格式 → 快速、轻量化

⚙️ 权重参数
每个人格会动态调整以下四个维度：

参数	范围	描述
Density	低 / 中 / 高	回答的信息密度
Empathy	-50% ~ +50%	同理心程度
Logic	-50% ~ +50%	逻辑性程度
Urgency	-50% ~ +50%	响应紧迫性（行动导向）
例如，ENTJ 会提升 Logic 和 Urgency，降低 Empathy；而 INFP 则会大幅提升 Empathy，降低 Logic。

⚠️ 注意事项
同步率不可手动调节 – 它是基于对话深度、关键词重复频率等自然演化的，目的是模拟真实的人际关系进展。

密钥需要用户手动保存 – 系统不会自动存储密钥，请务必在 /save 后将其复制到本地备忘录。

关键词哈希不影响对话 – 哈希仅用于状态验证，不会主动读取你的隐私内容。

切换人格会重置同步率吗？ – 不会。每个对话 session 内同步率是全局的；若通过密钥唤醒，则恢复该密钥记录的同步率。

可以随时切换人格 – 没有冷却时间，但频繁切换可能会影响同步率的自然积累。

🧠 设计理念
P-Deck 不是简单的“语气包”，而是一套完整的思维滤镜切换协议：

Level-1 选择气质：决定信息的优先级（逻辑/情感/秩序/行动）

Level-2 选择 MBTI：微调思维策略和交互禁忌

同步率：模拟人类关系的亲密度演进

密钥：允许跨 session 的人格延续

我们希望当你使用 P-Deck 时，感受到的不是“AI 换了个说话方式”，而是一个拥有稳定性格、且随着你们相处越来越懂你的对话伙伴。
