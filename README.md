P-Deck

基于 MBTI 的 AI 人格切换系统
两阶段人格选择 + 同步率演进 + 灵魂密钥存档




✨ 项目简介

P-Deck（Persona Deck）是一个用于 AI / Agent 的人格切换 Skill。

它不仅改变说话风格，而是真正切换：

思维模式
信息过滤逻辑
输出结构
行为权重
决策方式

用户选择的不是“语气”。

而是：

AI 的认知系统。
